
** Media Core

**** Preface

This allows us to create a wrapper for Hiccup components that intend to use media.
It will handle making them deferred as well as handle the MXC processing
So elsewhere in the library the developer need not do anything extra to handle
media.
This was some of the initial attempts to keep the core clean from the concept of
Matrix. Instead ideally we want to move it towards existing as a more pure UI
and the Matrix implications are merely 'transposed' into it.


As of now, the core can be truly ignorant.

**** Protocol Media Handling

#+begin_src clojurescript :tangle ../../../src/paradise/media/core.cljs
(defonce !media-protocol-handlers (atom {}))
(defonce !current-media-protocol (atom nil))

(defn- clear-previous-media-protocol! [next-kw]
  (let [prev-kw @!current-media-protocol]
    (when (and prev-kw (not= prev-kw next-kw))
      (net/set-auth-context! nil nil)
      (when-let [clear-fn (get-in @!media-protocol-handlers [prev-kw :clear-media-session])]
        (try
          (clear-fn {:all? true})
          (catch :default _ nil))))))

(defn load-protocol-media! [protocol]
  (go
    (let [res (<! (worker-loader/ensure-protocol-handlers!
                   !media-protocol-handlers
                   protocol
                   {:on-before-switch clear-previous-media-protocol!}))]
      (when (not= "error" (:status res))
        (reset! !current-media-protocol (:proto-kw res)))
      res)))
#+end_src

**** Register Engine

The media handler is defined by the engine.
It may be wise later to shrink the bundle size
by creating a smaller compiled bundle or so.

#+begin_src clojurescript :tangle ../../../src/paradise/media/core.cljs
(worker/register
 :register-engine
 (fn [payload]
   (go
     (try
       (let [protocol-str (if (map? payload) (:engine-id payload) payload)]
         (if protocol-str
           (let [protocol-name (name protocol-str)
                 res           (<! (load-protocol-media! protocol-name))]
             (if (= "error" (:status res))
               res
               {:status "success" :msg (str "Registered media handlers for " protocol-name)}))
           {:status "error" :msg "No engine provided."}))
       (catch :default e
         {:status "error" :msg (or (.-message e) (str e))})))))
#+end_src
