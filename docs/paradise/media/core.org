
** Media Core

**** Preface

This allows us to create a wrapper for Hiccup components that intend to use media.
It will handle making them deferred as well as handle the MXC processing
So elsewhere in the library the developer need not do anything extra to handle
media.
This was some of the initial attempts to keep the core clean from the concept of
Matrix. Instead ideally we want to move it towards existing as a more pure UI
and the Matrix implications are merely 'transposed' into it.


As of now, the core can be truly ignorant.

**** Protocol Media Handling

#+begin_src clojurescript :tangle ../../../src/paradise/media/core.cljs
(defonce !loaded-media-engines (atom #{}))

(defn load-protocol-media! [protocol]
  (go
    (<! (registry/ensure-environment!))
    (let [proto-kw (keyword protocol)]
      (when-not (contains? @!loaded-media-engines proto-kw)
        (if-let [url (registry/get-engine-url protocol)]
          (do
            (<p! (dynamic-import url))
            (swap! !loaded-media-engines conj proto-kw))
          (throw (js/Error. (str "Unknown protocol or missing registry URL: " protocol))))))))
#+end_src
