
** Worker Core

**** Preface

As we've built this out it becomes apparent there would be a tangible gain to separating
the behavior that is ONLY rust-sdk operations from the UI code.
This would allow our start-up to feel much more instantaneous and incredibly more responsive.

As far as documentation goes, some of it will be ported from the prior implementations location
if applicable.

Going beyond that. It makes sense to actually break the SDK away from the repo
and instead bind it and reference it. This gives us a smoother experience
and enables us to support multiple protocols and not just Matrix.

**** Dynamic Runtime Engine Loading

This is enables us to take a compiled JS bundle and ingest it to use the engine
it is associated with.


What was initially the fallback trigger, is now the main mechanism used
for bootstrapping. It is easy then to neatly load the engine in.

We do ensure to keep it in a form so that it can remain ignorant of the
actual protocol.

#+begin_src clojurescript :tangle ../../../src/paradise/engine/core.cljs
(defn get-fallback-bootstrap [protocol]
  (let [prop-name (str (str/capitalize protocol) "EngineBootstrap")]
    (js/console.error prop-name)
    (gobj/get js/globalThis prop-name)))
#+end_src



***** Load


#+begin_src clojurescript :tangle ../../../src/paradise/engine/core.cljs
(defn load-protocol-engine! [protocol]
  (go
    (<! (registry/ensure-environment!))
    (try
      (let [url (registry/get-engine-url protocol)]
        (if-not url
          {:status "error" :msg (str "Unknown protocol or missing registry URL: " protocol)}
          (let [_            (<p! (dynamic-import url))
                bootstrap-fn (get-fallback-bootstrap protocol)]
            (if bootstrap-fn
              (<! (bootstrap-fn register-engine!))
              (js/console.error "Engine module did not export a bootstrap function:" protocol)))))
      (catch js/Error e
        (js/console.error "External import failed:" e)))))
#+end_src



***** Register RPC

This lets the engine be informed of what engine is being registered

#+begin_src clojurescript :tangle ../../../src/paradise/engine/core.cljs
(worker/register :register-engine
                 (fn [payload]
                   (go
                     (try
                       (let [protocol-str (if (map? payload) (:engine-id payload) payload)]
                         (if protocol-str
                           (let [protocol-name (name protocol-str)]
                             (<! (load-protocol-engine! protocol-name))
                             (let [engine-map (get @!registry (keyword protocol-name))
                                   preload-fn (:preload engine-map)]
                               (when preload-fn
                                 (preload-fn))
                               {:status "success" :msg (str "Registered engine " protocol-name)}))
                           {:status "error" :msg "No engine provided."}))
                       (catch :default e
                         (js/console.error "Engine Registration Crash:" e)
                         {:status "error" :msg (.-message e)})))))
#+end_src
