
** The Service Worker


**** Preface

So a web-based matrix client usually follows the pattern of using service workers
to provide long-lived functionality. This includes background behavior when we
say use it even as a native app or a PWA on phones. It is through the service
worker that we can asynchronously fetch images from the server or deliver push notifications.
It is safe to say that the service worker is a very important component to
most web applications, not just web-based Matrix clients.

***** Message Event

The message event is how the client communicates with the service worker.
It passes 'messages' to the service worker and the service worker passes
'messages' to the client. It is not too dissimilar to postMessage for
communicating with iframes.

https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage

(.addEventListener js/self "message"
  (fn [event]
    (let [data      (.-data event)
          msg-type  (when data (.-type data))
          source-id (some-> event .-source .-id)]
      (cond
        (= msg-type "SKIP_WAITING")
        (.skipWaiting js/self)

        (= msg-type "SET_SESSION")
        (let [session-data (:session (js->clj data :keywordize-keys true))
              session-key  (or (:user-id session-data) source-id :default)
              full-session (assoc session-data :client-id source-id)
              next-map     (swap! active-sessions assoc session-key full-session)]
          (persist-sw-sessions! next-map)
          (doseq [resolve-fn @session-resolvers]
            (resolve-fn true))
          (reset! session-resolvers []))))))

****** Session waiting

We need to wait until a session is available to start performing fetches.
Without this, the user could end up seeing broken images purely from their
client loading too fast and trying to fetch.
#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn- persist-sw-sessions! [sessions-map]
  (p/catch
    (p/let [dir      (.. js/navigator -storage getDirectory)
            handle   (.getFileHandle dir sw-session-file #js {:create true})
            writable (.createWritable handle)
            _        (.write writable (js/JSON.stringify (clj->js sessions-map)))
            _        (.close writable)]
      true)
    (fn [_] nil)))

(defn- load-sw-sessions []
  (p/catch
    (p/let [dir    (.. js/navigator -storage getDirectory)
            handle (.getFileHandle dir sw-session-file)
            file   (.getFile handle)
            text   (.text file)]
      (js->clj (js/JSON.parse text) :keywordize-keys true))
    (fn [_] {})))

#+end_src


****** Vault Token Retrieval

Now this is great if we want to do simple behavior, but the moment we expect
long-living persistence we might wish to instead check against the IndexedDB
for individual sessions for a user. This way we can actually support
multiple accounts at once reliably for even our notification purposes.

Now the immediate thought is that because the Rust SDK pickles our data at
rest we'd need some way to actually unlock it. So the second part of this
is to create a small entry in our IndexedDB in which we create entries
with the access token.

#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn- resolve-session [client-id user-id]
  (let [mem @active-sessions]
    (if (seq mem)
      (p/resolved
       (or (when client-id (get mem client-id))
           (when user-id (first (filter #(= (:user-id %) user-id) (vals mem))))
           (first (vals mem))))
      (p/let [stored (load-sw-sessions)]
        (when (seq stored)
          (reset! active-sessions stored)
          (or (when user-id (get stored (keyword user-id)))
              (when user-id (get stored user-id))
              (first (vals stored))))))))
#+end_src


****** Old cache management


If possible we want to manage the cache and we want to also make sure we don't
cache items that are too old. By caching we provide a level of offline access.

One might wonder about the cache security. It is true that on desktop
the cache is not encrypted by default, but it is however isolated and secure.

The browser ensures this much at least. It would be the expectation of the
user to encrypt their device. The performance impact of encrypting and
decrypting the cache would be noticeable to the performance of the application.
Not to mention entirely impractical as if an attacker has access to the cache then
they also have access to the key to decrypt it.

For mobile users can take solace we can rely on the fact their operating system
encrypt the disk at rest (Full Disk Encryption).

#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn prune-cache! [name max-items]
  (p/let [cache (js/caches.open name)
          keys  (.keys cache)]
    (when (> (.-length keys) max-items)
      (p/let [_ (.delete cache (first keys))]
        (prune-cache! name max-items)))))
#+end_src


***** Fetch Event

The fetch event is vital for the client to asynchronously 'fetch' images from a
server so that we may allow the client to worry simply on the elements it can
render immediately.

We only want to bother fetching authenticated media with the expected
media endpoints. We validate the URL to ensure we don't leak info unexpectedly.

Some important readings for this:
https://spec.matrix.org/latest/client-server-api/#matrix-content-mxc-uris

https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/fetch_event

We also want to utilize a cache so that users don't bother endlessly re-fetching assets on reloads.
We make sure that we split the logic into two branches. Non-authenticated media and authenticated media.
For any other browser fetch we want to simply return it back to the browser to handle.
#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn- cacheable-media-response? [resp]
  (when (and resp (.-ok resp))
    (let [ct  (or (.get (.-headers resp) "content-type") "")
          len (js/parseInt (or (.get (.-headers resp) "content-length") "0") 10)]
      (and (or (str/starts-with? ct "image/")
               (str/starts-with? ct "video/")
               (str/starts-with? ct "audio/")
               (str/starts-with? ct "application/octet-stream"))
           (or (js/isNaN len) (zero? len) (< len MAX_CACHE_BYTES))))))

(defn- matches-media-path? [path session]
  (let [patterns (or (seq (:media-paths session)) ["/media/"])]
    (boolean (some #(str/includes? path %) patterns))))

(js/self.addEventListener "fetch"
  (fn [event]
    (let [request     (.-request event)
          method      (.-method request)
          request-url (js/URL. (.-url request))
          path        (.-pathname request-url)
          dest        (.-destination request)]
      (when (and (= method "GET")
                 (or (#{"image" "video" "audio"} dest)
                     (str/includes? path "/media/")))
        (.respondWith event
          (p/let [cache-key (.-href request-url)
                  cache     (js/caches.open cache-name)
                  cached    (.match cache cache-key)]
            (if cached
              cached
              (if (.has (.-headers request) "Authorization")
                (p/let [resp (js/fetch request)]
                  (when (cacheable-media-response? resp)
                    (.put cache cache-key (.clone resp)))
                  resp)
                (p/let [session (resolve-session (.-clientId event) nil)
                        token   (:token session)
                        origin  (:origin session)
                        headers (js/Headers. (.-headers request))]
                  (if (or (#{"image" "video" "audio"} dest)
                          (matches-media-path? path session))
                    (do
                      (when (and token (= (.-origin request-url) origin))
                        (.set headers "Authorization" (str "Bearer " token)))
                      (p/let [resp (js/fetch request-url #js {:headers     headers
                                                              :mode        "cors"
                                                              :credentials "omit"})]
                        (when (cacheable-media-response? resp)
                          (.put cache cache-key (.clone resp)))
                        resp))
                    (js/fetch request)))))))))))

(defn- array-buffer->data-url [buf mime-type]
  (let [bytes  (js/Uint8Array. buf)
        len    (.-byteLength bytes)
        chunks #js []]
    (dotimes [i len]
      (.push chunks (js/String.fromCharCode (aget bytes i))))
    (str "data:" (or mime-type "image/png") ";base64," (js/btoa (.join chunks "")))))

(defn- build-avatar-url [session raw-uri]
  (cond
    (str/blank? (str raw-uri))
    nil

    (or (str/starts-with? (str raw-uri) "http://")
        (str/starts-with? (str raw-uri) "https://")
        (str/starts-with? (str raw-uri) "data:"))
    (str raw-uri)

    (and (:base-url session) (:thumbnail-template session))
    (let [clean-id (-> (str raw-uri)
                       (str/replace #"^[a-zA-Z0-9+.-]+://" ""))]
      (-> (:thumbnail-template session)
          (str/replace "{base-url}" (str/replace (:base-url session) #"/+$" ""))
          (str/replace "{id}" clean-id)))

    :else nil))

(defn- fetch-avatar-data-url [session avatar-uri]
  (if-let [thumb-url (build-avatar-url session avatar-uri)]
    (if (str/starts-with? thumb-url "data:")
      (p/resolved thumb-url)
      (let [token   (:token session)
            headers (if token
                      #js {:Authorization (str "Bearer " token)}
                      #js {})]
        (-> (js/fetch thumb-url #js {:headers     headers
                                     :mode        "cors"
                                     :credentials "omit"})
            (p/then (fn [resp]
                      (when (.-ok resp)
                        (p/let [mime (.get (.-headers resp) "content-type")
                                buf  (.arrayBuffer resp)]
                          (array-buffer->data-url buf mime)))))
            (p/catch (fn [_] nil)))))
    (p/resolved nil)))

(defn- normalize-push-payload [raw-map]
  (let [room-id  (or (:room_id raw-map) (:room-id raw-map) (:roomId raw-map) (:channel_id raw-map))
        event-id (or (:event_id raw-map) (:event-id raw-map) (:eventId raw-map))
        user-id  (or (:account_id raw-map) (:user_id raw-map) (:user-id raw-map) (:userId raw-map))]
    (cond-> raw-map
      room-id  (assoc :room_id room-id :room-id room-id :roomId room-id)
      event-id (assoc :event_id event-id :event-id event-id :eventId event-id)
      user-id  (assoc :account_id user-id :user_id user-id :user-id user-id :userId user-id))))

(defn- request-client-decryption [raw-map timeout-ms]
  (p/let [clients (.matchAll js/self.clients #js {:type "window" :includeUncontrolled true})
          client  (first clients)]
    (if-not client
      nil
      (js/Promise.
       (fn [resolve-fn _]
         (let [chan      (js/MessageChannel.)
               port1     (.-port1 chan)
               port2     (.-port2 chan)
               norm-data (clj->js (normalize-push-payload raw-map))
               timer     (js/setTimeout #(do (.close port1) (resolve-fn nil)) timeout-ms)]
           (set! (.-onmessage port1)
                 (fn [ev]
                   (js/clearTimeout timer)
                   (.close port1)
                   (resolve-fn (.-data ev))))
           (.postMessage client
                         #js {:type    "RESOLVE_PUSH"
                              :payload norm-data}
                         #js [port2])))))))

(defn- parse-push-event [event]
  (when-let [event-data (.-data event)]
    (try
      (let [parsed (.json event-data)]
        (or (.-notification parsed) parsed))
      (catch :default _
        (let [raw-text (try (.text event-data) (catch :default _ "New Message"))]
          #js {:title "Paradise"
               :body  (if (str/blank? raw-text) "New Message" raw-text)})))))

(defn- fallback-notification [raw]
  (let [sender     (or (:sender_display_name raw) (:sender raw) (:title raw) "Paradise")
        room-name  (or (:room_name raw) (:channel_name raw))
        encrypted? (boolean (or (:encrypted raw)
                                (some-> (:type raw) (str/includes? "encrypted"))))]
    {:title      (if room-name (str sender " in " room-name) sender)
     :body       (if encrypted?
                   "Encrypted Message"
                   (or (:content_body raw)
                       (get-in raw [:content :body])
                       (:body raw)
                       "New Message"))
     :avatar-uri (or (:avatar_uri raw)
                     (:avatar_url raw)
                     (get-in raw [:content :avatar_url])
                     (:sender_avatar_url raw)
                     (:icon raw))
     :room-id    (or (:room_id raw) (:room-id raw) (:channel_id raw))
     :unread     (or (:unread raw) (get-in raw [:counts :unread]) (get-in raw [:aps :badge]))}))

(defn- show-notification! [notif session]
  (let [title      (:title notif)
        body       (:body notif)
        avatar-uri (or (:avatar-uri notif) (:avatar_uri notif) (:avatar_url notif) (:icon notif))
        room-id    (or (:room-id notif) (:room_id notif) (:roomId notif))
        raw-unread (:unread notif)
        unread     (cond
                     (number? raw-unread) raw-unread
                     (string? raw-unread) (let [n (js/parseInt raw-unread 10)]
                                            (when-not (js/isNaN n) n))
                     :else nil)]
    (when (exists? js/navigator.setAppBadge)
      (try
        (if (and unread (pos? unread))
          (.setAppBadge js/navigator unread)
          (when (= unread 0)
            (.clearAppBadge js/navigator)))
        (catch :default _ nil)))
    (p/let [icon-url (fetch-avatar-data-url session avatar-uri)]
      (.showNotification js/self.registration (or title "Paradise")
        #js {:body  (or body "New Message")
             :icon  (or icon-url default-icon)
             :badge default-badge
             :tag   (or room-id "paradise-chat")
             :data  #js {:room_id room-id}}))))

***** Registering the Service Worker

The major functionality we need is to register the service worker itself.
We do so while passing off the session token so that the service worker
may immediately begin to render our images.
#+begin_src clojurescript :tangle ../../src/service_worker_handler.cljs
(defn register-sw! []
  (when (exists? js/navigator.serviceWorker)
    (let [sw-container js/navigator.serviceWorker
          try-sync!    (fn []
                         (-> sw-container
                             .-ready
                             (.then (fn [_]
                                      (re-frame/dispatch [:auth/sync-sw-with-worker])))))]
      (-> (.register sw-container "/sw.js" #js {:type "module"})
          (.then (fn [reg]
                   (when (.-waiting reg)
                     (.postMessage (.-waiting reg) #js {:type "SKIP_WAITING"})))))
      (try-sync!)
      (.addEventListener sw-container "controllerchange"
                         (fn []
                           (log/debug "re-frame: SW Controller changed, checking version...")
                           (try-sync!)
                           (-> (check-remote-version)
                               (p/then (fn [remote-v]
                                         (let [db        @db/app-db
                                               current-v (get-in db [:config :version] "0.0.0")]
                                           (when (and remote-v
                                                      (not= (str remote-v) (str current-v))
                                                      (not= (str current-v) "0.0.0"))
                                             (log/info "SW Update: Version mismatch detected" remote-v "vs" current-v)
                                             (re-frame/dispatch [:app/clear-cache-for-update])))))
                               (p/catch (fn [err]
                                          (log/error "SW Update: Failed to check version" err))))))
      (.addEventListener sw-container "message"
                         (fn [event]
                           (let [data     (.-data event)
                                 msg-type (when data (.-type data))]
                             (cond
                               (= msg-type "NAVIGATE_TO_ROOM")
                               (let [room-id (.-room_id data)]
                                 (log/debug "SW requested navigation to room:" room-id)
                                 (re-frame/dispatch [:rooms/select room-id]))

                               (= msg-type "RESOLVE_PUSH")
                               (when-let [reply-port (aget (.-ports event) 0)]
                                 (let [raw-payload (js->clj (.-payload data) :keywordize-keys true)
                                       with-data   (assoc raw-payload :data raw-payload)
                                       args        (assoc with-data :payload with-data)]
                                   (log/debug "SW requested push decryption for payload:" raw-payload)
                                   (go
                                     (let [res (<! (mesh/do-with-thread!
                                                    :engine-pool
                                                    {:handler   :resolve-push-notification
                                                     :arguments args}))]
                                       (if (#{"success" :success} (:status res))
                                         (.postMessage reply-port (clj->js (:notification res)))
                                         (do
                                           (log/warn "Push decryption did not resolve:" res)
                                           (.postMessage reply-port nil))))))))))))))

                            origin   (when base-url (.-origin (js/URL. base-url)))
                            payload  (assoc session
                                            :base-url base-url
                                            :token    token
                                            :user-id  user-id
                                            :origin   origin)]
                        (.postMessage sw-active #js {:type    "SET_SESSION"
                                                     :session (clj->js payload)})
                        (js/console.log "re-frame: Session synced for" user-id "at" origin))
                      (catch js/Error e
                        (js/console.error "re-frame: Failed to parse session base-url" e)))
                    (js/console.warn "re-frame: SW active worker not found"))))))))
