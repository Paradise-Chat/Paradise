
** The Service Worker


**** Preface

So a web-based matrix client usually follows the pattern of using service workers
to provide long-lived functionality. This includes background behavior when we
say use it even as a native app or a PWA on phones. It is through the service
worker that we can asynchronously fetch images from the server or deliver push notifications.
It is safe to say that the service worker is a very important component to
most web applications, not just web-based Matrix clients.

***** Message Event

The message event is how the client communicates with the service worker.
It passes 'messages' to the service worker and the service worker passes
'messages' to the client. It is not too dissimilar to postMessage for
communicating with iframes.

https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage

#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(.addEventListener js/self "message"
  (fn [event]
    (let [data      (.-data event)
          msg-type  (when data (.-type data))
          source-id (some-> event .-source .-id)]
      (cond
        (= msg-type "SKIP_WAITING")
        (.skipWaiting js/self)

        (= msg-type "CLEAR_SESSION")
        (let [payload    (when data (js->clj data :keywordize-keys true))
              target-uid (some-> (:user-id payload) str not-empty)
              all?       (or (:all? payload) (nil? target-uid))]
          (if all?
            (do
              (reset! active-sessions {})
              (reset! active-client-sessions {})
              (reset! active-user-id nil)
              (remove-sw-sessions-file!)
              (purge-media-caches! nil))
            (let [next-map (swap! active-sessions dissoc target-uid (keyword target-uid))]
              (swap! active-client-sessions
                     (fn [m]
                       (into {} (remove (fn [[_ v]] (= (str (:user-id v)) target-uid)) m))))
              (when (= (str @active-user-id) target-uid)
                (reset! active-user-id nil))
              (if (seq next-map)
                (persist-sw-sessions! next-map)
                (remove-sw-sessions-file!))
              (purge-media-caches! target-uid))))

        (= msg-type "CLEAR_ALL_SESSIONS")
        (do
          (reset! active-sessions {})
          (reset! active-client-sessions {})
          (reset! active-user-id nil)
          (remove-sw-sessions-file!)
          (purge-media-caches! nil))

        (= msg-type "SET_SESSION")
        (let [raw-session  (:session (js->clj data :keywordize-keys true))
              session-data (select-keys raw-session
                                        [:user-id :base-url :origin :token
                                         :auth-media? :media-paths :thumbnail-template])
              uid          (some-> (:user-id session-data) str not-empty)
              session-key  (or uid source-id "default")
              full-session (assoc session-data :client-id source-id)
              next-map     (swap! active-sessions assoc session-key full-session)]
          (when source-id
            (swap! active-client-sessions assoc source-id full-session))
          (reset! active-user-id uid)
          (persist-sw-sessions! next-map)
          (doseq [resolve-fn @session-resolvers]
            (resolve-fn true))
          (reset! session-resolvers []))))))
#+end_src


****** Session waiting

We need to wait until a session is available to start performing fetches.
Without this, the user could end up seeing broken images purely from their
client loading too fast and trying to fetch.
#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn- persist-sw-sessions! [sessions-map]
  (p/catch
    (p/let [dir      (.. js/navigator -storage getDirectory)
            handle   (.getFileHandle dir sw-session-file #js {:create true})
            writable (.createWritable handle)
            _        (.write writable (js/JSON.stringify (clj->js sessions-map)))
            _        (.close writable)]
      true)
    (fn [_] nil)))

(defn- remove-sw-sessions-file! []
  (p/catch
    (p/let [dir (.. js/navigator -storage getDirectory)]
      (.removeEntry dir sw-session-file))
    (fn [_] nil)))

(defn- purge-media-caches! [target-uid]
  (p/catch
    (p/let [keys (.keys js/caches)]
      (let [prefix (if target-uid
                     (str legacy-cache-name "::" (js/encodeURIComponent (str target-uid)))
                     legacy-cache-name)]
        (p/all
         (for [k keys
               :when (if target-uid
                       (or (= k prefix) (= k legacy-cache-name))
                       (str/starts-with? k legacy-cache-name))]
           (.delete js/caches k)))))
    (fn [_] nil)))

(defn- load-sw-sessions []
  (p/catch
    (p/let [dir    (.. js/navigator -storage getDirectory)
            handle (.getFileHandle dir sw-session-file)
            file   (.getFile handle)
            text   (.text file)]
      (let [parsed (js/JSON.parse text)]
        (reduce (fn [acc k]
                  (assoc acc k (js->clj (aget parsed k) :keywordize-keys true)))
                {}
                (js/Object.keys parsed))))
    (fn [_] {})))

#+end_src


****** Vault Token Retrieval

Now this is great if we want to do simple behavior, but the moment we expect
long-living persistence we might wish to instead check against the IndexedDB
for individual sessions for a user. This way we can actually support
multiple accounts at once reliably for even our notification purposes.

Now the immediate thought is that because the Rust SDK pickles our data at
rest we'd need some way to actually unlock it. So the second part of this
is to create a small entry in our IndexedDB in which we create entries
with the access token.

#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(defn- find-session-by-uid [sessions-map uid]
  (when (and (seq sessions-map) uid)
    (let [uid-str (str uid)]
      (or (get sessions-map uid-str)
          (get sessions-map (keyword uid-str))
          (first (filter #(= (str (:user-id %)) uid-str) (vals sessions-map)))))))

(defn- resolve-session [client-id user-id]
  (let [mem        @active-sessions
        client-hit (when client-id (get @active-client-sessions client-id))]
    (cond
      user-id
      (if-let [hit (find-session-by-uid mem user-id)]
        (p/resolved hit)
        (p/let [stored (load-sw-sessions)]
          (when (seq stored)
            (swap! active-sessions merge stored)
            (find-session-by-uid stored user-id))))

      client-hit
      (p/resolved client-hit)

      (and client-id (seq mem))
      (p/resolved
       (or (first (filter #(= (:client-id %) client-id) (vals mem)))
           (when-let [cur @active-user-id]
             (find-session-by-uid mem cur))))

      @active-user-id
      (p/resolved (find-session-by-uid mem @active-user-id))

      :else
      (p/resolved nil))))
#+end_src


****** Fetch Event

Persistent cross-platform media caching is handled uniformly in IndexedDB
(~paradise.shared.client.cache~) across Web, Electron, iOS, and Android. The
service worker therefore intercepts only authenticated media paths to inject
the active session's ~Authorization~ bearer header without double-caching
images in ~CacheStorage~.

#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(def default-auth-media-paths
  ["/_matrix/client/v1/media/"
   "/_matrix/media/"])

(defn- matches-auth-media-path? [path session]
  (when (and (string? path)
             (not (false? (:auth-media? session)))
             (not (str/starts-with? path "/_matrix/media/v3/preview_url"))
             (not (str/starts-with? path "/_matrix/client/v1/media/preview_url")))
    (let [patterns (if (contains? session :media-paths)
                     (:media-paths session)
                     default-auth-media-paths)]
      (boolean (and (seq patterns)
                    (some (fn [pat]
                            (and (string? pat)
                                 (str/starts-with? pat "/")
                                 (str/starts-with? path pat)))
                          patterns))))))

(defn- likely-authenticated-path? [path]
  (and (string? path)
       (not (str/starts-with? path "/_matrix/media/v3/preview_url"))
       (not (str/starts-with? path "/_matrix/client/v1/media/preview_url"))
       (boolean (some #(str/starts-with? path %) default-auth-media-paths))))

(js/self.addEventListener "fetch"
  (fn [event]
    (let [request     (.-request event)
          method      (.-method request)
          request-url (js/URL. (.-url request))
          protocol    (.-protocol request-url)
          path        (.-pathname request-url)]
      (when (and (= method "GET")
                 (#{"http:" "https:"} protocol)
                 (likely-authenticated-path? path)
                 (not (.has (.-headers request) "Authorization")))
        (.respondWith event
          (p/let [session    (resolve-session (.-clientId event) nil)
                  token      (:token session)
                  origin     (:origin session)
                  need-auth? (and token
                                  origin
                                  (= (.-origin request-url) origin)
                                  (matches-auth-media-path? path session))]
            (if need-auth?
              (let [headers (js/Headers. (.-headers request))]
                (.set headers "Authorization" (str "Bearer " token))
                (js/fetch request-url #js {:headers        headers
                                           :mode           "cors"
                                           :credentials    "omit"
                                           :redirect       "error"
                                           :referrerPolicy "no-referrer"}))
              (js/fetch request))))))))
#+end_src

***** Push Notifications

So an important part to the service worker use is providing the web application
a way to receive notifications from the background. The general standard implementation
is WebPush denoted below:
https://developer.mozilla.org/en-US/docs/Web/API/Push_API

Now the implementation for these is relatively standardized (though for Clojurescript
perhaps a bit less so).
We want to simply add the push event listener and then parse the data out.
We handle the requests in the form Sygnal delivers (though I'm unsure if
the form is entirely ubiquitous across any push gateway implementation).
For the sake of these docs currently, I'll be referring to them in the
context of the Matrix solution Sygnal.
https://github.com/element-hq/sygnal/blob/main/docs/applications.md#webpush

We also go on to include a notification click in order to provide the future
behavior on which clicking a notification brings that message into focus.
Currently, however, it won't be functional as we have not implemented a go-to
method for messages yet.

It does seem unfortunately that we have no way to determine the recipient of a push...
Perhaps I'll spend more time on the problem another time, but it is best we get
this functional first.
#+begin_src clojurescript :tangle ../../src/service_worker.cljs
(def default-icon "/public/res/apple/apple-touch-icon-180x180.png")
(def default-badge "/public/res/apple/apple-touch-icon-72x72.png")

(defn- build-avatar-url [session raw-uri]
  (let [s (str raw-uri)]
    (cond
      (str/blank? s)
      nil

      (or (str/starts-with? s "http://")
          (str/starts-with? s "https://")
          (str/starts-with? s "data:"))
      s

      (and (:base-url session) (:thumbnail-template session))
      (let [clean-id (str/replace s #"^[a-zA-Z0-9+.-]+://" "")]
        (when (and (not (str/blank? clean-id))
                   (not (str/includes? clean-id ".."))
                   (not (str/includes? clean-id "\\"))
                   (not (str/includes? clean-id "?"))
                   (not (str/includes? clean-id "#"))
                   (not (re-find #"\s" clean-id)))
          (-> (:thumbnail-template session)
              (str/replace "{base-url}" (str/replace (:base-url session) #"/+$" ""))
              (str/replace "{id}" clean-id))))

      :else nil)))

(defn- fetch-avatar-data-url [session avatar-uri]
  (if-let [thumb-url (build-avatar-url session avatar-uri)]
    (if (str/starts-with? thumb-url "data:")
      (p/resolved thumb-url)
      (let [parsed     (try (js/URL. thumb-url) (catch :default _ nil))
            valid-http (and parsed (#{"http:" "https:"} (.-protocol parsed)))]
        (if-not valid-http
          (p/resolved nil)
          (let [token      (:token session)
                origin     (:origin session)
                need-auth? (and token
                                origin
                                (= (.-origin parsed) origin)
                                (matches-auth-media-path? (.-pathname parsed) session))
                fetch-opts (if need-auth?
                             #js {:headers        #js {:Authorization (str "Bearer " token)}
                                  :mode           "cors"
                                  :credentials    "omit"
                                  :redirect       "error"
                                  :referrerPolicy "no-referrer"}
                             #js {:mode           "cors"
                                  :credentials    "omit"
                                  :referrerPolicy "no-referrer"})]
            (-> (js/fetch (.-href parsed) fetch-opts)
                (p/then (fn [resp]
                          (when (.-ok resp)
                            (p/let [mime (.get (.-headers resp) "content-type")
                                    buf  (.arrayBuffer resp)]
                              (array-buffer->data-url buf mime)))))
                (p/catch (fn [_] nil)))))))
    (p/resolved nil)))

(defn- normalize-push-payload [raw-map]
  (let [room-id  (or (:room_id raw-map) (:room-id raw-map) (:roomId raw-map) (:channel_id raw-map))
        event-id (or (:event_id raw-map) (:event-id raw-map) (:eventId raw-map))
        user-id  (or (:account_id raw-map) (:user_id raw-map) (:user-id raw-map) (:userId raw-map))]
    (cond-> raw-map
      room-id  (assoc :room_id room-id :room-id room-id :roomId room-id)
      event-id (assoc :event_id event-id :event-id event-id :eventId event-id)
      user-id  (assoc :account_id user-id :user_id user-id :user-id user-id :userId user-id))))

(defn- request-client-decryption [raw-map timeout-ms]
  (p/let [clients (.matchAll js/self.clients #js {:type "window" :includeUncontrolled true})
          client  (first clients)]
    (if-not client
      nil
      (js/Promise.
       (fn [resolve-fn _]
         (let [chan      (js/MessageChannel.)
               port1     (.-port1 chan)
               port2     (.-port2 chan)
               norm-data (clj->js (normalize-push-payload raw-map))
               timer     (js/setTimeout #(do (.close port1) (resolve-fn nil)) timeout-ms)]
           (set! (.-onmessage port1)
                 (fn [ev]
                   (js/clearTimeout timer)
                   (.close port1)
                   (resolve-fn (.-data ev))))
           (.postMessage client
                         #js {:type    "RESOLVE_PUSH"
                              :payload norm-data}
                         #js [port2])))))))

(defn- parse-push-event [event]
  (when-let [event-data (.-data event)]
    (try
      (let [parsed (.json event-data)]
        (or (.-notification parsed) parsed))
      (catch :default _
        (let [raw-text (try (.text event-data) (catch :default _ "New Message"))]
          #js {:title "Paradise"
               :body  (if (str/blank? raw-text) "New Message" raw-text)})))))

(defn- fallback-notification [raw]
  (let [sender     (or (:sender_display_name raw) (:sender raw) (:title raw) "Paradise")
        room-name  (or (:room_name raw) (:channel_name raw))
        encrypted? (boolean (or (:encrypted raw)
                                (some-> (:type raw) (str/includes? "encrypted"))))]
    {:title      (if room-name (str sender " in " room-name) sender)
     :body       (if encrypted?
                   "Encrypted Message"
                   (or (:content_body raw)
                       (get-in raw [:content :body])
                       (:body raw)
                       "New Message"))
     :avatar-uri (or (:avatar_uri raw)
                     (:avatar_url raw)
                     (get-in raw [:content :avatar_url])
                     (:sender_avatar_url raw)
                     (:icon raw))
     :room-id    (or (:room_id raw) (:room-id raw) (:channel_id raw))
     :unread     (or (:unread raw) (get-in raw [:counts :unread]) (get-in raw [:aps :badge]))}))

(defn- show-notification! [notif session]
  (let [title      (:title notif)
        body       (:body notif)
        avatar-uri (or (:avatar-uri notif) (:avatar_uri notif) (:avatar_url notif) (:icon notif))
        room-id    (or (:room-id notif) (:room_id notif) (:roomId notif))
        raw-unread (:unread notif)
        unread     (cond
                     (number? raw-unread) raw-unread
                     (string? raw-unread) (let [n (js/parseInt raw-unread 10)]
                                            (when-not (js/isNaN n) n))
                     :else nil)]
    (when (exists? js/navigator.setAppBadge)
      (try
        (if (and unread (pos? unread))
          (.setAppBadge js/navigator unread)
          (when (= unread 0)
            (.clearAppBadge js/navigator)))
        (catch :default _ nil)))
    (p/let [icon-url (fetch-avatar-data-url session avatar-uri)]
      (.showNotification js/self.registration (or title "Paradise")
        #js {:body  (or body "New Message")
             :icon  (or icon-url default-icon)
             :badge default-badge
             :tag   (or room-id "paradise-chat")
             :data  #js {:room_id room-id}}))))

(js/self.addEventListener "push"
  (fn [event]
    (let [raw-js  (parse-push-event event)
          raw-map (if raw-js (js->clj raw-js :keywordize-keys true) {})
          user-id (or (:account_id raw-map)
                      (:user_id raw-map)
                      (:user-id raw-map)
                      (:userId raw-map))]
      (.waitUntil event
        (p/let [session  (resolve-session nil user-id)
                resolved (when (seq raw-map) (request-client-decryption raw-map 1500))
                notif    (if resolved
                           (js->clj resolved :keywordize-keys true)
                           (fallback-notification raw-map))]
          (notify-open-clients-push! notif raw-map)
          (show-notification! notif session))))))

#+begin_src clojurescript :tangle ../../src/service_worker_handler.cljs
(defonce !explicit-update-reload? (atom false))

(defn- clear-app-caches!
  "Purges runtime asset caches (IDB assets/meta + non-media CacheStorage) while
   preserving cached user media (avatars, emotes, stickers)."
  []
  (p/all
   [(-> (cache/clear-runtime-assets!)
        (p/catch (fn [_] nil)))
    (if (exists? js/caches)
      (-> (.keys js/caches)
          (p/then (fn [cache-keys]
                    (p/all
                     (for [k cache-keys
                           :when (not (str/starts-with? (str k) "paradise-media-v1"))]
                       (.delete js/caches k)))))
          (p/catch (fn [_] nil)))
      (p/resolved nil))]))

(re-frame/reg-event-fx
 :app/apply-update
 (fn [_ _]
   (-> (clear-app-caches!)
       (p/then
        (fn [_]
          (if (exists? js/navigator.serviceWorker)
            (-> (.getRegistration js/navigator.serviceWorker)
                (.then (fn [reg]
                         (let [waiting-sw (when reg (.-waiting reg))]
                           (if waiting-sw
                             (do
                               (log/info "Telling new SW to activate...")
                               (reset! !explicit-update-reload? true)
                               (.postMessage waiting-sw #js {:type "SKIP_WAITING"})
                               (js/setTimeout
                                (fn []
                                  (when @!explicit-update-reload?
                                    (reset! !explicit-update-reload? false)
                                    (.reload js/window.location)))
                                1500))
                             (do
                               (log/info "No waiting SW found, hard reloading...")
                               (.reload js/window.location))))))
                (.catch (fn [_]
                          (.reload js/window.location))))
            (.reload js/window.location)))))
   {}))

(re-frame/reg-event-fx
 :app/clear-cache-for-update
 (fn [_ _]
   (log/warn "Purging runtime caches and service workers for update...")
   (-> (p/let [_    (clear-app-caches!)
               regs (if (exists? js/navigator.serviceWorker)
                      (-> (.getRegistrations js/navigator.serviceWorker)
                          (p/catch (fn [_] #js [])))
                      (p/resolved #js []))
               _    (p/all (map #(-> (.unregister %) (p/catch (fn [_] false))) regs))]
         (.reload js/window.location))
       (p/catch (fn [_]
                  (.reload js/window.location))))
   {}))

***** Registering the Service Worker

The major functionality we need is to register the service worker itself.
We do so while passing off the session token so that the service worker
may immediately begin to render our images.
#+begin_src clojurescript :tangle ../../src/service_worker_handler.cljs
(defonce !sw-listeners-installed? (atom false))
(defonce !had-sw-controller? (atom false))

(defn- activate-waiting-sw! [sw-worker]
  (when sw-worker
    (.postMessage sw-worker #js {:type "SKIP_WAITING"})))

(defn- watch-sw-registration! [sw-container reg]
  (when reg
    (when-let [waiting-sw (.-waiting reg)]
      (activate-waiting-sw! waiting-sw))
    (.addEventListener
     reg
     "updatefound"
     (fn []
       (when-let [installing-sw (.-installing reg)]
         (.addEventListener
          installing-sw
          "statechange"
          (fn []
            (when (and (= (.-state installing-sw) "installed")
                       (.-controller sw-container))
              (activate-waiting-sw! installing-sw)))))))
    (-> (.update reg)
        (.catch (fn [_] nil)))))

(defn register-sw! []
  (when (exists? js/navigator.serviceWorker)
    (let [sw-container js/navigator.serviceWorker
          try-sync!    (fn []
                         (-> sw-container
                             .-ready
                             (.then (fn [_]
                                      (re-frame/dispatch [:auth/sync-sw-with-worker])))))]
      (when (.-controller sw-container)
        (reset! !had-sw-controller? true))
      (-> (.register sw-container "/sw.js" #js {:type "module" :updateViaCache "none"})
          (.then (fn [reg]
                   (watch-sw-registration! sw-container reg)))
          (.catch (fn [err]
                    (log/warn "SW registration skipped or failed:" err))))
      (try-sync!)
      (when (compare-and-set! !sw-listeners-installed? false true)
        (.addEventListener
         sw-container
         "controllerchange"
         (fn []
           (if (compare-and-set! !explicit-update-reload? true false)
             (.reload js/window.location)
             (let [replaced-existing? @!had-sw-controller?]
               (reset! !had-sw-controller? true)
               (log/debug "re-frame: SW Controller changed, checking version...")
               (try-sync!)
               (-> (check-remote-version)
                   (p/then
                    (fn [remote-v]
                      (let [db        @db/app-db
                            current-v (or bundled-version
                                          (get-in db [:config :bundled-version])
                                          (get-in db [:config :version]))
                            mismatch? (and remote-v
                                           current-v
                                           (not= (str remote-v) (str current-v)))]
                        (cond
                          mismatch?
                          (do
                            (log/info "SW Update: Version mismatch detected"
                                      remote-v "vs" current-v)
                            (if (claim-update-reload! remote-v)
                              (re-frame/dispatch [:app/clear-cache-for-update])
                              (re-frame/dispatch [:app/update-detected])))

                          replaced-existing?
                          (do
                            (log/info "SW Update: New service worker took control; prompting refresh.")
                            (-> (cache/clear-runtime-assets!)
                                (p/catch (fn [_] nil)))
                            (re-frame/dispatch [:app/update-detected]))))))
                   (p/catch (fn [err]
                              (log/error "SW Update: Failed to check version" err)
                              (when replaced-existing?
                                (re-frame/dispatch [:app/update-detected])))))))))
        (.addEventListener
         sw-container
         "message"
         (fn [event]
           (let [data     (.-data event)
                 msg-type (when data (.-type data))]
             (cond
               (= msg-type "NAVIGATE_TO_ROOM")
               (let [room-id (.-room_id data)]
                 (log/debug "SW requested navigation to room:" room-id)
                 (re-frame/dispatch [:rooms/select room-id]))

               (= msg-type "PUSH_NOTIFICATION_RECEIVED")
               (re-frame/dispatch [:notif/push-audio-cue
                                   {:room-id  (.-room_id data)
                                    :event-id (.-event_id data)}])

               (= msg-type "RESOLVE_PUSH")
               (when-let [reply-port (aget (.-ports event) 0)]
                 (let [raw-payload (js->clj (.-payload data) :keywordize-keys true)
                       with-data   (assoc raw-payload :data raw-payload)
                       args        (assoc with-data :payload with-data)]
                   (log/debug "SW requested push decryption")
                   (go
                     (let [res (<! (mesh/do-with-thread!
                                    :engine-pool
                                    {:handler   :resolve-push-notification
                                     :arguments args}))]
                       (if (#{"success" :success} (:status res))
                         (.postMessage reply-port (clj->js (:notification res)))
                         (do
                           (log/warn "Push decryption did not resolve:" (:status res))
                           (.postMessage reply-port nil)))))))))))))))

***** Syncing to the Service Worker with Reframe

Now, since we're using reframe we want to ensure we're providing our rendering
implementation an easy way to inform updates to the service worker.
We may wish to break this apart a bit for re-usability, but for now this will do.
#+begin_src clojurescript :tangle ../../src/service_worker_handler.cljs
(re-frame/reg-event-fx
 :auth/sync-sw-with-worker
 (fn [{:keys [db]} [_ attempt]]
   (let [tries (or attempt 0)]
     (if (= (:auth-status db) :logged-in)
       (do
         (go
           (let [res (<! (mesh/do-with-thread! :engine-pool {:handler :get-client-context}))]
             (if (#{"success" :success} (:status res))
               (re-frame/dispatch [:auth/sync-sw-only (:session res)])
               (when (< tries 6)
                 (js/setTimeout
                  #(re-frame/dispatch [:auth/sync-sw-with-worker (inc tries)])
                  750)))))
         {})
       {:clear-sw-auth {:all? true}}))))

(re-frame/reg-event-fx
 :auth/sync-sw-only
 (fn [_ [_ session]]
   {:sync-sw-auth session}))

(re-frame/reg-event-fx
 :auth/clear-sw-session
 (fn [_ [_ opts]]
   {:clear-sw-auth (or opts {:all? true})}))

(re-frame/reg-fx
 :clear-sw-auth
 (fn [{:keys [user-id all?]}]
   (when (exists? js/navigator.serviceWorker)
     (-> (.-ready js/navigator.serviceWorker)
         (.then (fn [reg]
                  (when-let [sw-active (.-active reg)]
                    (if (or all? (nil? user-id))
                      (.postMessage sw-active #js {:type "CLEAR_ALL_SESSIONS"})
                      (.postMessage sw-active #js {:type    "CLEAR_SESSION"
                                                   :user-id (str user-id)})))))
         (.catch (fn [_] nil))))))

(re-frame/reg-fx
 :sync-sw-auth
 (fn [session]
   (when (and session (exists? js/navigator.serviceWorker))
     (-> (.-ready js/navigator.serviceWorker)
         (.then (fn [reg]
                  (if-let [sw-active (.-active reg)]
                    (try
                      (let [base-url    (or (:server-url session)
                                            (:base-url session))
                            parsed-u    (when base-url (js/URL. base-url))
                            valid-http? (and parsed-u (#{"http:" "https:"} (.-protocol parsed-u)))
                            origin      (when valid-http? (.-origin parsed-u))
                            auth-media? (not (false? (:auth-media? session)))
                            token       (when (and valid-http? auth-media?)
                                          (or (:token session) (:accessToken session)))
                            user-id     (or (:user-id session) (:userId session))
                            payload     (cond-> {:user-id     user-id
                                                 :base-url    (when valid-http? base-url)
                                                 :origin      origin
                                                 :auth-media? auth-media?}
                                          token
                                          (assoc :token token)

                                          (contains? session :media-paths)
                                          (assoc :media-paths (:media-paths session))

                                          (:thumbnail-template session)
                                          (assoc :thumbnail-template (:thumbnail-template session)))]
                        (.postMessage sw-active #js {:type    "SET_SESSION"
                                                     :session (clj->js payload)})
                        (js/console.log "re-frame: Session synced for" user-id "at" origin))
                      (catch js/Error e
                        (js/console.error "re-frame: Failed to parse session base-url" e)))
                    (js/console.warn "re-frame: SW active worker not found"))))))))
#+end_src
